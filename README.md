# Ponds Concentrate Nutrients: The Roles of Internal Features, Land Use, and Climate — Code Repository

## Overview

This repository contains the code used for the analyses and figure generation associated with the manuscript:

**“Why Ponds Concentrate Nutrients: The Roles of Internal Features, Land Use, and Climate”**
DOI: 10.1007/s10750-025-05907-0

The `scripts/` directory includes the main R scripts used in the study. Scripts are organised according to their primary function (e.g., preprocessing, modelling, and figure generation), with file names reflecting the analyses or figures produced.

## Data Availability

The datasets supporting this study are available from the authors upon reasonable request.
